Every window
in its place.

Mosaico arranges your windows into a layout the moment they open, so you spend your time in them instead of dragging them around. Hold Alt and the keyboard does the rest.

A status bar for the rest

Workspaces, layout, clock, CPU and RAM at the top of each monitor. Themed, configurable, and reloaded the moment you save.

Or never open a config file.

The settings window covers every option, from gaps and borders to bar widgets, keybindings and window rules. Search finds a setting on any page, and Apply reloads mosaico on the spot.

Click the pages in the sidebar to look around. Open it from the tray icon, or run mosaico settings.

Script it.

Lua scripts read the desktop, react to what happens on it and act on it. Float the meeting window, switch layouts when you dock, run a command every time you change workspace.

  • Each script runs in its own process, so one that fails, loops or crashes only stops itself.
  • Events for windows opening, moving and closing, focus, workspaces, layouts, monitors and config reloads.
  • mosaico script new starts one from a template, and your editor completes the whole API.
  • Run a script when you sign in with mosaico script autostart enable, or bind it to a key.
  • Not a Lua person? mosaico events --json streams the same events to any language.

Read the scripting guide

scripts\meeting.lua
-- Float meeting windows over the tiles
mosaico.on("window_managed", function(e)
  if e.title:find("Meeting") then
    mosaico.float(e.window)
  end
end)
PowerShell
PS> mosaico script run meeting

The full cheatsheet

Try it today.

Free and open source. One command installs it for your user, with no dependencies and no admin rights, and mosaico update keeps it current.

PowerShell
PS> irm https://raw.githubusercontent.com/jmelosegui/mosaico/main/docs/install.ps1 | iex

Or with winget Coming soon

PowerShell
PS> winget install jmelosegui.mosaico

Then start it, and check your setup if anything looks off:

PowerShell
PS> mosaico start
PS> mosaico doctor
